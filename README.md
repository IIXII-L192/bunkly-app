# Bunkly

Bunkly is an Android app for tracking class attendance, planning bunks, and staying aware of attendance requirements.

## What It Does

- Track subject-wise attendance for theory and practical classes.
- Add and manage a weekly timetable.
- Mark classes as present, absent, event duty, holiday, or weekly off.
- Plan safe bunks against a target attendance percentage.
- Simulate future attendance changes before making decisions.
- View monthly attendance logs for present and absent records.
- Manage a local profile and privacy preferences.
- Create and restore local backup files.

## Download

APK files are published on the **Releases** page of this repository.

Open the latest release, download the APK, and install it on your Android device.

## Notes

- Bunkly stores attendance data locally on your device.
- Keep your backup files safe if you are changing phones or reinstalling the app.
- Some online features are marked as work in progress and may not be available yet.
